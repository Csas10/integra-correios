# Templates oficiais Correios

Os binários XLSX permanecem fora deste repositório público. O ZIP recebido foi
inspecionado somente para extrair nomes, hashes e cabeçalhos. As linhas de
exemplo não foram copiadas.

Contratos tipados:

- remetentes: 15 colunas;
- destinatários: 15 colunas;
- objetos simples: 34 colunas;
- objetos registrados sem código: 87 colunas.

Consulte `MANIFEST.sha256` antes de usar um original documental. O importador
valida cabeçalhos, mas não pressupõe dados de demonstração.
